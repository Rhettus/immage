# Translating Immage

The UI text lives in one JSON file per language in
[`app/src/locales`](../../src/locales): `en.json` is the reference and the
fallback, `fr.json` is a translation. [i18n.ts](../../src/i18n.ts) loads the
language chosen in Preferences > General > Language (or the system's) once at
start-up, and the page reloads when it is changed.

## In code

```ts
import { t } from "./i18n";
t("menu.export")                       // a text
t("import.done", { count: 3 })         // "{count}" in the text is replaced
t("photos", { n: 3 })                  // tries "photos_one" / "photos_other" first
```

Keys are semantic (`menu.export`), not the English text. `t()` can be called at
module level, since settings are loaded before the app is imported. A key
missing from a language shows the English text, so a translation can be partial.

## Adding a language

1. Copy `en.json` to `<code>.json` (for example `es.json`) and translate the
   values. Keep every `{placeholder}` as it is.
2. In [i18n.ts](../../src/i18n.ts), import it and add it to `LOCALES` with its
   own name (`es: { name: "Español", dict: es }`).
3. Run `node --test verify/locales.test.mjs`: it fails on a key that is not in
   `en.json` and on a changed `{placeholder}`.

## Converting a screen

Replace each text with `t("area.name")` and add the key to `en.json` (and to
`fr.json`). The menus ([menu.ts](../../src/menu.ts), drawn by
[MenuBar.tsx](../../src/MenuBar.tsx)) and every tab of Preferences
([Preferences.tsx](../../src/Preferences.tsx), [CachePrefs.tsx](../../src/CachePrefs.tsx),
[ModulePrefs.tsx](../../src/ModulePrefs.tsx), [ImmichPrefs.tsx](../../src/ImmichPrefs.tsx),
[PluginPrefs.tsx](../../src/PluginPrefs.tsx), [MapSearchPrefs.tsx](../../src/MapSearchPrefs.tsx))
are done; the rest of the UI is still English.

A `PrefRow` takes the translated text as `label`, and its English name as `id`
(`data-pref-label`), which the GUI checks in `verify/gui` find a row by.
Keep the `id` when a row's label is converted. Names of panels and controls
not yet converted (Basic, Exposure, Negative...) stay in English inside the
French texts, so they match what the screen shows.

Do not decide anything from a translated text (a status line's style, a
lookup): keep a flag or the English `id` beside it, as `ImmichPrefs` does for
its warning line.

License and copyright notices (About's GPL and map attribution paragraphs) stay
in English on purpose: they are the legal wording.
